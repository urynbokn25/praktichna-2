# Практична робота з Git
Цей проєкт створений для виконання практичних завдань та демонстрації роботи з системою контролю версій Git та сервісом GitHub.
## Встановлення та запуск
Для налаштування проєкту локально виконайте команди у терміналі:
```bash
git clone https://github.com
cd praktichna-2
```
## Основні функції
- Фіксація змін та робота з гілками.
- Оформлення документації за допомогою розмітки Markdown.
- Публікація коду на віддаленому репозиторії.
## Технології
| Інструмент | Призначення |
| :--- | :--- |
| Git | Контроль версій |
| GitHub | Хостинг репозиторію |
